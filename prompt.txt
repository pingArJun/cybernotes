# Prompt for Building CyberNotes System

Here's the exact prompt you should give me when you're ready to build:

---

**PROMPT:**

```
Build me a localhost cybersecurity knowledge management web application called "CyberNotes" with these requirements:

CORE FEATURES:
1. Project Management - organize by type (Malware Analysis, Bug Bounty, CTF, Research, Course, Custom)
2. Quick Capture - fast note taking during active work
3. Commands Library - store commands with outputs, ONE-CLICK COPY buttons for every command
4. Walkthroughs - step-by-step writeups with markdown support
5. Resources - manage courses, tools, documentation links with progress tracking
6. Files - upload and store screenshots, scripts, pcaps (base64 storage)
7. Templates - pre-built templates for CTF writeups, bug reports, malware analysis
8. Checklists - methodology checklists with nested items
9. Tags System - organize everything with tags
10. Search - full-text search across all content
11. Version History - track changes to notes and walkthroughs
12. Export/Backup - export individual projects or full backup as JSON

TECHNICAL REQUIREMENTS:
- React application with Tailwind CSS
- Use persistent storage (window.storage API) for all data
- Dark theme with modern cybersecurity aesthetic
- Sidebar navigation with all main sections
- Each command MUST have a prominent copy button
- File upload with drag & drop support
- Markdown editor for notes and walkthroughs
- Search with filters (by project, type, date, tags)
- Responsive design, collapsible sidebar

UI STRUCTURE:
- Header: Logo, global search, quick actions
- Sidebar: Dashboard, Quick Capture, Projects, Commands, Walkthroughs, Templates, Resources, Checklists, Tags, Search, Settings
- Main content area that changes based on selection

DATA MODELS:
- Projects: id, name, type, status, description, tags, dates, stats
- Notes: id, project_id, title, content, type, tags, dates
- Commands: id, project_id, command_text, output_text, tool, purpose, success, tags, dates
- Resources: id, title, url, type, category, tags, progress, dates
- Files: id, project_id, filename, file_data (base64), file_type, size, dates
- Templates: id, name, template_type, content, variables
- Checklists: id, name, category, items (with nested structure)
- Tags: id, name, category

KEY INTERACTIONS:
1. Quick Capture: Fast form to create notes/commands on the fly
2. Commands: Grid/list view with copy buttons, filter by tool/tag, click to see full details
3. Projects: Create new project, view all associated notes/commands/files
4. Walkthroughs: Rich markdown editor with command insertion from library
5. Search: Filter by multiple criteria, show results from all content types

START WITH:
Phase 1 - Build the core structure:
- Basic layout (header, sidebar, main content)
- Storage initialization
- Projects CRUD (create, read, update, delete)
- Quick Capture functionality
- Commands library with COPY buttons
- Basic search

Make it functional and polished. Use modern UI with good UX. Every command must be easily copyable with one click.
```

## **TIPS FOR WORKING WITH ME:**

1. **Be specific about bugs**: If something doesn't work, tell me exactly what's broken with error messages

2. **Iterate in phases**: Don't ask for everything at once. Build core → test → add features → test

3. **Request changes clearly**: 
   - "Make the copy button bigger and green"
   - "Add a confirmation dialog before deleting projects"
   - "The search isn't finding commands, fix it"

4. **Test as you go**: After each phase, test the features and report issues

5. **Ask for explanations**: If you want to understand how something works, just ask

6. **Request specific features**: 
   - "Add a 'duplicate command' button"
   - "Make the sidebar resizable"
   - "Add syntax highlighting for Python code"
