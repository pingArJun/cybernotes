🎯 STEP 1: Open Terminal
   Open a terminal window in this directory

🎯 STEP 2: Navigate to Application Folder
   cd cybernotes

🎯 STEP 3: Install Dependencies (First Time Only)
   npm install

🎯 STEP 4: Start the Application
   npm run dev

🎯 STEP 5: Open in Browser
   Go to: http://localhost:5173/

⚡ MOST IMPORTANT FEATURE: COMMANDS LIBRARY
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Every command has a prominent COPY button!

1. Store commands you use frequently:
   - nmap -sC -sV -p- TARGET
   - gobuster dir -u http://TARGET -w wordlist.txt
   - sqlmap -u "http://TARGET?id=1" --dbs

2. Click COPY button

3. Paste in terminal

Never type the same command twice!

🎓 RECOMMENDED WORKFLOW
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

During Active CTF/Bug Bounty/Pentest:
───────────────────────────────────────
1. Create a new Project for the engagement
2. Use Quick Capture to take notes as you work
3. Add commands to Commands Library
4. Click COPY when you need to reuse them
5. Export backup when done

After Completing a Challenge:
────────────────────────────────
1. Go to Templates
2. Select "CTF Challenge Walkthrough"
3. Fill in each section
4. Insert commands from your Commands Library
5. Export as markdown for publishing

💾 BACKUP YOUR DATA!
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

All data is stored locally in your browser (IndexedDB).

To backup:
1. Go to Settings
2. Click "Export All Data"
3. Save the JSON file somewhere safe

To restore:
1. Go to Settings
2. Click "Import"
3. Select your backup JSON file

Backup weekly (at minimum)!

🛠️ TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Problem: Application won't start
Solution:
   cd cybernotes
   rm -rf node_modules
   npm install
   npm run dev

Problem: Data not saving
Solution:
   - Don't use incognito/private mode
   - Check browser storage permissions

Problem: Copy button not working
Solution:
   - Check clipboard permissions in browser
   - Try Chrome or Firefox

Full troubleshooting guide in WALKTHROUGH.md
